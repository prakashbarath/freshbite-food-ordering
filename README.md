# 🍔 FreshBite - Online Food Ordering Platform

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://your-username.github.io/freshbite-food-ordering/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-blue)](https://github.com/your-username/freshbite-food-ordering)

FreshBite is a responsive, modern online food ordering frontend application. It allows users to browse food categories, apply dietary filters, add/remove dishes in a dynamic cart, calculate delivery totals, and complete a simulated checkout process.

## ✨ Features

### 🌟 Core Features
- **Hero & Landing Section:** Engaging hero banner with clean call-to-actions.
- **Dynamic Menu Grid:** Populated dynamically using JavaScript objects and arrays.
- **Category & Dietary Filtering:** Instant filtering for Pizza, Burgers, Biryani, Desserts, and Veg/Non-Veg options.
- **Interactive Shopping Cart Drawer:** Real-time quantity adjustment, subtotal & delivery fee calculations.
- **Local Storage Persistence:** Cart data persists across browser refreshes.
- **Simulated Checkout & Order Placement:** Modal-based checkout collecting user address and payment mode.
- **Responsive Navigation:** Mobile hamburger menu with smooth transitions.

### 🎁 Bonus Features
- 🥗 Veg / Non-Veg Visual Indicators
- 💳 Simulated Multi-Payment Options (COD, Card, UPI)
- 📱 Cross-device responsive design (Mobile, Tablet, Desktop)
